Immersive mode

Optional setup

Let the browser step back. Reveal your tabs and address bar at the top edge, then return to an uninterrupted page.

Download userChrome.css

Set up immersive mode
  1. Download the file using the button above.
  2. Type about:support in Firefox’s address bar and press Enter. Beside Profile Folder, click Open Folder.
  3. Open the chrome folder inside that profile. If it is missing, create it. Move the downloaded userChrome.css into it.
  4. Open about:config, search for toolkit.legacyUserProfileCustomizations.stylesheets, and set it to true.
  5. Use horizontal tabs and turn off Title Bar in Customize Toolbar. In about:keyboard, assign F2 to Toggle Bookmarks Toolbar.
  6. Fully restart Firefox and maximize the window normally. Press F2 to switch modes. No F11 needed.

Keep bookmarks on New Tab: right-click an empty toolbar area → Bookmarks Toolbar → Only Show on New Tab. F2 changes that same preference; reselect it if needed.

Already have a userChrome.css? Back it up before replacing it. If it contains other customizations you want to keep, merge our downloaded file into it instead. Replace any older Slipframe immersive section rather than adding a second copy.

Designed for maximized desktop Firefox with horizontal tabs; tested by the user on Windows. The F2 setup requires Firefox 147+. To undo, remove our stylesheet or restore your backup and restart. The extension never changes your profile files automatically.
